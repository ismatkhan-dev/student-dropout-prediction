# Student Dropout and Academic Success Prediction

## Project Overview
This project aims to predict student academic outcomes using Machine Learning. It focuses on identifying students who may Dropout, remain Enrolled, or Graduate.

## Dataset Information
- Total Records: 4,424
- Total Columns: 37
- Input Features: 36
- Target Column: Target
- Missing Values: 0
- Duplicate Records: 0

## Target Distribution

| Student Status | Count | Percentage |
|---|---:|---:|
| Graduate | 2,209 | 49.93% |
| Dropout | 1,421 | 32.12% |
| Enrolled | 794 | 17.95% |
